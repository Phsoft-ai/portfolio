STT Model

강의 녹음을 인터넷 없이, 휴대폰 안에서, 무료로 글로 바꾸기 위해 한국어 받아쓰기 모델 Notesoop-STT-Ko-v2를 직접 학습했습니다.

Hugging Face ↗
59초 41분 강의를 받아쓰는 시간
12배 Whisper-large-v3보다 빠르게
더 정확 오류율 4.4%p 낮음 (vs Whisper)
0원 사용자는 무료 · 무제한

Why.

외부 받아쓰기 API는 비싸고, 녹음을 서버로 보내야 합니다. 그래서 기기 안에서 도는 모델을 직접 만들기로 했습니다.

Free

사용량 걱정 없이

API 비용이 들지 않아 모든 사용자에게 무제한으로 열어둘 수 있어요.

Private

녹음이 밖으로 나가지 않게

수업 녹음이 휴대폰 밖으로 전송되지 않아요.

Lecture

강의에 강하게

강의 음성 300GB에 일상 대화 230GB를 더해, 총 530GB로 학습했어요.

Result.

실제 대학 전공 강의 41분 43초 녹음으로 비교했습니다. (M1 Pro 노트북 기준)
