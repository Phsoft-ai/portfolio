STT Model

Notesoop-STT-Ko-v2 — 530GB 한국어 음성 코퍼스로 학습하고 Apache-2.0으로 공개한 차세대 한국어 온디바이스 음성인식(ASR) 모델입니다. 비자기회귀 단일 패스 구조와 C++17 빔 서치로 초고속·초경량 전사를 실현했습니다.

Hugging Face 모델 카드 ↗
42.2x 41분 43초 강의 59.3초 전사 (Whisper-large-v3 대비 11.9배)
10.47% Zeroth-Korean CER (V1 15.88% 대비 -5.41%p)
1.39GB 실전 MPS VRAM (Whisper-large-v3 6.3GB 대비 4.5배 적음)
< 1ms Native C++17 Rolling-Hash CTC Beam Search

Technical Architecture.

동결된 Google EmbeddingGemma-2 오디오 인코더 표현(MRL 256차원) 위에 경량 Conformer 음향 리더, 2,048 BPE 초구면 코사인 CTC 헤드, 서브밀리초 네이티브 C++17 빔 서치와 5-Gram KenLM 언어 디코더를 결합한 비자기회귀(Non-Autoregressive) 아키텍처를 설계했습니다.

01 Audio Input 16kHz Mono → 128-Bin Log-Mel
02 Frozen Backbone EmbeddingGemma-2 (MRL 256-dim)
03 Conformer Reader 10-Layer (34.3M, d=384, h=6, k=15)
04 Cosine CTC Head Spherical Cosine · 2,048 BPE
05 C++17 + KenLM Rolling-Hash(<1ms) · 5-Gram LM
06 Chunk Merge Fuzzy LCS 중복 제거·정리
구조 / 벤치마크 이미지
개발 환경 : PyTorch (MPS · CUDA · CPU) / C++17 / Apple Metal Compute Shader
학습 파라미터 : 34.8M (배포 체크포인트 133MB + KenLM 5-Gram 80.2MB)
학습 데이터 : 총 530GB (AI Hub 전공 강의 300GB + 자유 대화 230GB)
라이선스 : Apache-2.0 (Hugging Face 오픈소스 공개)

설계 목표

  • 1) 비자기회귀 단일 패스 구조로 장시간 강의 전사 시 환각을 억제하고 수십 배속 실시간 처리 달성
  • 2) 1.3~1.4GB 초경량 메모리로 8GB/16GB 맥북·모바일에서 PDF 필기 앱과 동시에 쾌적하게 실행
  • 3) 강의뿐 아니라 자유 대화·인터뷰·즉흥 구어체까지 아우르는 범용 한국어 인식력 확보

Apple M1 Pro (16GB, PyTorch MPS bfloat16) 실측 기준, 실제 대학 전공 강의 롱폼 녹음과 공인 표준 벤치마크(Zeroth-Korean)에서 대형 모델 및 V1 대비 속도와 메모리·정확도 모두를 검증했습니다.

Challenge & Solution.

No. Challenge Solution Result
01 V1의 25,000 형태소·음절 사전으로 인한 출력 차원 비대화, OOV 취약성 및 2.6GB Host RAM 점유 2,048 SentencePiece BPE로 출력 차원을 12.2배 축소하고, 320만 문장 기반 5-Gram KenLM(80.2MB) 언어 모델을 결합 Zeroth-Korean CER -5.41%p·WER -10.21%p 개선 및 Host RAM 46.7% 절감(1,405MB)
02 강의 음성(300GB)만 학습 시 즉흥 구어체·추임새·빠른 발화 구간의 음향 강건성 저하 및 대규모 데이터 학습 비용 AI Hub 자유 대화 음성 230GB를 추가 결합해 총 530GB Zero-Disk 스트리밍 학습 파이프라인과 커스텀 Apple Metal Compute Shader 학습 엔진 구축 실전 41분 전공 강의 CER 21.19% 달성 (Whisper-large-v3 25.55% 대비 4.36%p 우위)
03 Python CTC 빔 서치 디코딩 병목과 슬라이딩 윈도우(15초 청크) 경계에서의 단어 중복·반복 현상 Native C++17 Rolling-Hash 빔 서치(<1ms)를 GPU 배치 포워드와 비동기 중첩 실행하고, 최대 8-어절 정확 매칭 + 문자 단위 Fuzzy LCS + 반복 필터 적용 41분 43초 강의를 59.3초(42.2x)에 전사하며 Whisper-large-v3 대비 11.9배 고속화
04 Apple Silicon MPS 중심이었던 V1의 타 플랫폼(NVIDIA CUDA · CPU) 배포 제약 device="auto" 백엔드 자동 감지(bfloat16 Fastpath)와 macOS/Linux/Windows C++ 공유 라이브러리 자동 빌드(Python Fallback 포함) 구현 크로스플랫폼 추론 지원 완성 및 Apache-2.0 오픈소스 공개
